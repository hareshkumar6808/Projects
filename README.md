## Getting started

Choose a repository and follow its README. Some projects need local development tools, datasets, or optional provider credentials. Keep API keys and private runtime data out of Git.

These projects have different maturity levels. See each repository's documented limitations and checks; an educational model or simulated demonstration is not a production guarantee.
